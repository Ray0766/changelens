# ChangeLens — 研究、设计与验收 brief

配合根目录 [AGENTS.md](../AGENTS.md) 使用。初次资料核对：2026-11-03。以下为待验证方案，未代表已实现能力。

## 要解决的任务与核心亮点

审阅者需要快速知道两版文档改了什么，并核对原文。建议优先验证“可解释的变化清单”：把内容、数值、位置和版式变化分开，将每条结论链接到旧版与新版的具体区域，减少重新分页带来的噪声。

首版只处理文字型 PDF：导入两版 → 页/块对齐 → 差异清单与原文联动 → 人工审查 → 导出报告。扫描件、OCR 和 Office 原生格式是后续能力。

## 技术探索应回答什么

1. 分层比较可见渲染、文本内容与几何位置；以纯文本 diff 和像素 diff 为基线，验证更复杂的块级对齐是否降低噪声且不遗漏关键变化。
2. 研究 PDF.js 等成熟组件的解析/渲染能力。只有布局识别确实失败时，才对照 Docling 等结构化解析或 VLM 方案；不得为原生文字 PDF 默认引入重型模型。
3. 字体、抗锯齿、旋转、坐标系、跨页段落、阅读顺序及重复内容要有明确处理方法。数值变化保留原始字符，不能因归一化吞掉负号、小数点或单位。
4. 页/块匹配置信度不足时允许人工重新配对，并标为未确定；摘要必须附原文定位，无法解析或未覆盖区域明确提示，不能输出“无变化”假结论。

## 优秀参考与转化方向

来源入口已核对；借鉴栏是建议而非已完成的视觉评测。选型时复核当前版本、维护状态、许可和自有样例表现。

| 参考 | 类型与用途 | 建议借鉴及边界 |
| --- | --- | --- |
| [PDF.js](https://mozilla.github.io/pdf.js/) | Mozilla 的 PDF 解析/渲染平台 | 研究渲染与文本定位能力；它本身不是完整的文档差异算法。 |
| [OmniDocBench 论文](https://arxiv.org/abs/2412.07626)及[作者仓库](https://github.com/opendatalab/OmniDocBench) | CVPR 2025 文档解析基准，仓库有后续维护 | 借鉴多版面、多语言、分任务评价；解析分数不能替代差异检测正确率，版本和数据许可需单独记录。 |
| [Docling](https://docling-project.github.io/docling/) | 结构化文档处理官方文档 | 作为复杂布局候选解析器研究；先与轻量基线比较依赖成本和误差。 |
| [diff-pdf](https://github.com/vslavik/diff-pdf) | 可视化 PDF 比较工具 | 建立像素差异基线；其 README 声明不积极开发，不能默认当作持续维护的核心依赖。 |
| [LiquidText](https://www.liquidtext.net/) | 文档阅读、注释与上下文关联产品 | 研究审查结论回到原文的交互，保留阅读上下文；不照搬笔记工作空间。 |

## 产品、内容与视觉方向

- 界面以文档页和差异定位为中心，提供清单＋双页视图。颜色编码有文字/图标补充，正文与标注保持清晰层级。
- 比较“文档优先”和“差异清单优先”两个布局；用包含长表格与多处修改的样例测试来选择。
- 变化表述具体，例如“第 3 页金额：8,000 → 9,500”，并展示两版页码、区域及变化类型。机器解释单列，避免用一段流畅摘要掩盖不确定性。
- 用户能区分移动、增加、删除、样式变化、疑似匹配和未处理区域；过滤差异应显式可见，不静默隐藏。
- 导出报告保留原文证据、比较方法与文件版本标识。脱离应用后仍可审阅；避免满屏装饰卡片及模糊的“AI 风险分”。

## 首版验收与演示

准备带明确真值的小型 PDF 对照集，至少覆盖：无改动、金额/负号/日期变化、插页、段落跨页重排、重复页、字体/位置变化及中英文混排。

| 检查 | 最小证据 |
| --- | --- |
| 关键内容 | 测试集中的数值、单位与删除变化全部能定位到两版原文；报告分项漏报和误报，不只报总准确率。 |
| 对齐 | 插页与重排不会让后续所有页面失配；不确定配对能被用户纠正。 |
| 渲染差异 | 抗锯齿等噪声处理前后对照，确认没有同时掩盖小字号或单字符变化。 |
| 异常与隐私 | 加密、损坏、扫描 PDF、超大文件给出明确支持边界；原文件不被修改，未授权不上传。 |
| 报告与性能 | 打开最终报告核对页码、区域、中文字体与分页；按文件规模记录耗时和峰值内存，阈值在实现前按目标环境定义。 |

代表性演示使用“金额改动＋分页重排”：既找到真正重要的变化，也解释为什么其他位置只是移动。测试集通过只证明该测试集，不能宣传覆盖所有 PDF。
